# Student_System

## Project Description
This project is program meant to mimic a school database system. It allows for the creation of classes, students, and teachers. Each of these objects stores further information, and the course is capable of keeping track of which students are enrolled in it. Students can be enrolled or removed from a course, and information for the selected object can be updated or wiped completely.

## Project Taskes
-  Task 1: Planning
    - Plan classes needed
    - Prepare tables needed for database
    - Map out interactions between tables and classes
- Task 2: Implement basic design
    - Create object classes
    - Create basic functions for objects
- Task 3: Implement database design
    - Create database classes
    - Implement connection access to database
- Task 4: Properlly integrate database interactions
    - Create functions to interact with database
    - Ensure read, write, update, and delete functions work
- Task 5: Finalize Project
    - Upload to GitHub
    - Document work

## Language Used
- **C#:** Used for primary application itself
- **SQL:** Used for handling database
